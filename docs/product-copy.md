# Codex Beacon 产品文案

## GitHub 仓库信息

- 仓库名：`codex-beacon`
- 简短描述：Windows 上的 Codex 任务状态信标：监控运行进度、提示待批准操作，并一键返回对应对话。
- Topics：`codex`、`tauri`、`react`、`typescript`、`rust`、`windows`、`desktop-app`、`productivity`

## 一句话介绍

不必守着 Codex 窗口，也能随时看见任务进度。

## 简短产品介绍

Codex Beacon 是一款 Windows 专用的 Codex 任务状态信标。它以紧凑的桌面悬浮岛显示当前任务、运行耗时、计划步骤、最近活动和最终回复；当任务等待批准或回复时，会切换为醒目的注意状态，并带你回到对应的 Codex 对话。

## 完整产品介绍

长任务交给 Codex 后，你不应该一直切回窗口确认它是否仍在运行。

Codex Beacon 常驻 Windows 桌面顶部，通过本地 Codex Hook 获取任务开始与完成事件，并只读解析对应的本地会话记录，持续显示当前任务、项目、耗时、最近动作和计划步骤。

当 Codex 等待批准或需要补充信息时，Codex Beacon 会用琥珀色状态提醒你。点击“前往批准”或“回到对话”，即可打开对应任务继续处理。批准决定仍由 Codex 完成，Codex Beacon 不接管审批。

所有状态都保存在本机，不上传任务内容，也不使用 CPU 占用猜测任务状态。

## 核心卖点

- 真实任务状态：通过 Codex Hook 和本地会话记录识别任务生命周期。
- 进度可见：显示最近动作与计划步骤，不伪造总体完成百分比。
- 注意提醒：区分进行中、完成、失败、失联、待批准和待回复。
- 精确返回：直接打开对应的 Codex Desktop 对话。
- Windows 原生体验：透明悬浮、始终置顶、系统托盘、开机启动和单实例。
- 本地优先：任务内容与状态均保留在本机。

## 适合谁

- 经常让 Codex 执行长时间编码、构建或分析任务的用户。
- 同时处理多个 Codex 任务，需要快速判断当前状态的用户。
- 希望减少反复切换窗口、又不想错过批准请求的 Windows 用户。

## 产品边界

- 当前仅支持 Windows 10/11 和 Codex。
- 计划步骤不是总体完成百分比。
- Codex Beacon 只提示待批准状态并跳回对话，不直接提交批准决定。
- 本项目是独立社区项目，与 OpenAI 无隶属、合作或官方背书关系。

## v0.4.0 Release 文案

### 标题

Codex Beacon v0.4.0 — 看见进度，及时处理

### 正文

Codex Beacon v0.4.0 已完成 Windows MVP 的核心闭环：

- 显示真实 Codex 任务、项目、耗时和最后回复。
- 从本地 rollout 补充最近活动与计划步骤。
- 识别待批准和待回复状态，并切换为琥珀色提醒。
- 通过“回到对话”精确打开对应 Codex 任务。
- 支持最近任务、并行会话识别、托盘、开机启动和单实例。
- 使用全新的 Codex Beacon 信标图标。

首次使用时，请启动应用并连接 Codex，然后在 Codex 的 Hooks 设置中审核并信任 Codex Beacon Hook。

当前版本仅支持 Windows 10/11。批准操作仍需在 Codex 中完成。
